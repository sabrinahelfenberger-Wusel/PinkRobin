# Robin-Firmware

Geplanter Einstieg: ESP32-S3 mit ESP-IDF, FreeRTOS und C/C++. Hier liegen künftig Hardwareadapter, Sensorik, Aktorik, Display und Gerätekommunikation sowie komponentennahe Tests.

Die fachliche Grundverhaltenslogik wird aus [core/](../core/) verwendet. Zielhardware und Toolchain werden beim Prototyp konkret geprüft und festgelegt.

Stand: Verzeichnisgerüst; noch keine Firmware implementiert.
