# Gemeinsamer Robin-Kern

Geplanter portabler C++-Verhaltenskern für Zustände, Ereignisse, Auftragsprüfung und Aktionskoordination. Hardware, Netzwerk und Oberfläche werden über Adapter angebunden.

Der gleiche Quellcode wird nativ für Firmware und Tests sowie mit Emscripten nach WebAssembly für den Angular-Websimulator gebaut. Native Kern-Tests und Browser-Bindung gehören zu dieser Komponente.

Stand: Verzeichnisgerüst; noch keine Implementierung. Grundlage: [Technologiekonzept](../docs/Technologiekonzept.md).
