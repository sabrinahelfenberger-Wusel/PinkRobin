# Virtual Robin

Erste eigenständig lauffähige Webversion von Pink Robin, ohne Build oder externe Abhängigkeiten.

`index.html` direkt im Browser öffnen. Den kompletten Ordner auf dem Webserver unter `/virtual-robin/` ablegen. Die Projektseite wird unter `/` erwartet; bei anderem Hosting den Zurück-Link anpassen.

Robin wacht auf, blinzelt, schaut sich um und stellt sich in einer Sprechblase vor. Der Button startet die Begegnung erneut. Körper, Arme und Herz bleiben statisch. Die Systemeinstellung für reduzierte Bewegung wird berücksichtigt. Keine Audioausgabe, Datenübertragung oder Speicherung.

Die Figur ist eine eigenständige SVG-Interpretation des Konzeptbildes. Die bestehende Projektseite wurde nicht verändert. Diese erste Version verwendet HTML, CSS und JavaScript; eine Angular-Integration ist noch nicht enthalten.
